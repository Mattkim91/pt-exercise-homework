# 임상 검토표

이 문서는 운동 추천 규칙을 코드에서 그대로 옮긴 것입니다. 추천 로직은 바꾸지 않았고, 운동 이름·방법·주의사항도 바꾸지 않았습니다.

출처는 `exercises.js`의 `BBS_RECOMMENDATIONS`, `presets`, `EXERCISES`와 `index.html`의 `activeBbsRecommendation`, `scoreExerciseForProfile`, `recommendAiExercises`, `safetyBanner`입니다.

운동은 번호, 한글 이름, 단계(`level`)만 적었습니다. 방법과 주의사항 문구는 여기에 다시 적지 않았습니다.

## BBS 구간 3개

운동 선택 화면의 BBS 점수는 `activeBbsRecommendation`이 고릅니다. 점수를 숫자로 바꾼 값이 0 이상 56 이하가 아니면 구간을 고르지 않습니다. 그 안이면 `min` 이상 `max` 이하인 첫 구간을 씁니다.

## 규칙 기반 추천 점수

추천 실행은 `recommendAiExercises`가 `scoreExerciseForProfile`로 운동마다 점수를 매긴 뒤 고릅니다. 외부 API는 호출하지 않습니다.

프로필에 쓰이는 값은 화면의 선택 목록과 같습니다.

- 진단/대상: stroke(Stroke), sci(SCI), tka(TKA), fall(낙상), elderly(고령), sarcopenia(근감소), cancer(Cancer), bedridden(와상), cardiac(심장), respiratory(호흡), ataxia(Ataxia)
- 기능 수준: bed(침상/와상), sitting(앉기 가능), standing(기립 가능), walking(보행 가능)
- 주요 목표: ROM, strength(근력), balance(균형), gait(보행), endurance(지구력), ADL, stretch(스트레칭)
- BBS 점수: 숫자 입력. 비어 있으면 BBS 가산점은 없습니다.

상태의 처음 기능 수준 값은 `moderate`입니다. 아래 네 값(bed, sitting, standing, walking)이 아니면 기능 수준 가감점도 없고, 뒤에 나오는 고정 번호 보정도 없습니다.

점수는 0에서 시작합니다. 아래 조건은 서로 따로 검사하고, 맞는 조건의 점수를 모두 더합니다.

1. 운동 `diagnosisTags`에 프로필 진단 값이 있으면 +5.
2. 진단이 `fall`이고, 태그에 `fall`이 있거나 목적 태그에 `balance` 또는 `gait`가 있으면 +5. 태그에 `fall`이 있으면 1번과 2번이 둘 다 적용됩니다.
3. 진단이 `tka`이고, 부위가 `knee` 또는 `hip`이거나 목적 태그에 `strength` 또는 `ROM`이 있으면 +3.
4. 진단이 `stroke`이고, 목적 태그에 `balance`, `gait`, `ADL` 중 하나가 있거나 부위가 `hand` 또는 `shoulder`이면 +2.
5. 진단이 `sci`이고, 목적 태그에 `ROM`, `strength`, `ADL` 중 하나가 있거나 부위가 `trunk`이면 +2.
6. 진단이 `cancer`이고, 목적 태그에 `endurance` 또는 `strength`가 있거나 단계 문자열에 `침상` 또는 `앉`이 있으면 +2.
7. 프로필 목표가 있고 운동 목적 태그에 그 목표 값이 있으면 +4.
8. 목표가 `gait`이고 부위가 `gait`이면 +3.
9. 목표가 `balance`이고 부위가 `balance`이면 +3.
10. 목표가 `strength`이고 목적 태그에 `strength`가 있으면 +3. 이 경우 7번도 맞으면 +4와 +3을 같이 받습니다.
11. 목표가 `ROM`이고 목적 태그에 `ROM` 또는 `PROM`이 있으면 +3. 목적 태그에 `ROM`이 있으면 7번의 +4도 같이 받습니다.
12. 기능 수준이 `bed`이면 단계에 `Lv0` 또는 `Lv1`이 있을 때 +5, `Lv4` 또는 `Lv5`가 있을 때 −6.
13. 기능 수준이 `sitting`이면 단계에 `Lv1` 또는 `Lv2`가 있을 때 +4, `Lv4` 또는 `Lv5`가 있을 때 −4.
14. 기능 수준이 `standing`이면 단계에 `Lv2` 또는 `Lv3`가 있을 때 +4, `Lv0`이 있을 때 −3.
15. 기능 수준이 `walking`이면 단계에 `Lv3`, `Lv4`, `Lv5` 중 하나가 있을 때 +4, `Lv0`이 있을 때 −4.
16. BBS 칸이 빈 문자열이 아니고 숫자로 바뀐 값이 숫자가 아니면 이 항목은 건너뜁니다. 숫자이면 다음 중 해당하는 것을 더합니다. 0 이하도 `20` 이하로 보고, `56`을 넘는 값도 `40` 초과로 봅니다. 입력칸의 0~56 제한과 별개입니다.
    - 점수가 20 이하이고 단계에 `Lv0`, `Lv1`, `Lv2` 중 하나가 있으면 +3.
    - 점수가 20 초과 40 이하이고 단계에 `Lv2` 또는 `Lv3`가 있으면 +3.
    - 점수가 40 초과이고 단계에 `Lv3` 또는 `Lv4`가 있으면 +3.
17. `imagePriority`가 `A`이면 +0.5.

이 BBS 가산점은 위의 BBS 구간 목록을 쓰지 않습니다. 구간 목록은 운동 선택 화면의 BBS 필터와 추천 담기만 씁니다.

고르는 순서는 다음과 같습니다.

1. 점수가 0보다 큰 운동만 남깁니다.
2. 점수가 높은 순으로 정렬합니다. 점수가 같으면 운동 번호가 작은 순입니다.
3. 앞에서 12개만 취합니다.
4. 기능 수준이 아래 값이면, 적힌 번호를 그 12개 앞에 붙인 뒤 중복을 제거하고 다시 앞에서 12개만 남깁니다. 그래서 앞에 붙은 번호가 점수 순위보다 우선합니다.

## 낙상 주의 문구 규칙

`safetyBanner`는 담긴 운동의 `caution` 문구를 빈칸으로 이어 붙인 뒤, 위에서부터 처음 맞는 문장 하나만 돌려줍니다.

1. 이어 붙인 문구에 `낙상`, `보호자`, `균형` 중 하나라도 있으면: 낙상 위험 — 반드시 보호자 감독 또는 지지물 가까이에서 시행하세요.
2. 그렇지 않고 `호흡` 또는 `숨`이 있으면: 운동 중 흉통·호흡곤란·어지러움 시 즉시 중단하세요.
3. 그렇지 않고 `통증`이 있으면: 통증이 심해지면 강도를 줄이거나 중단하세요.
4. 그 외: 안전한 범위에서 천천히 시행하고 불편감이 있으면 치료사에게 알려주세요.

담은 운동 화면에서는 운동이 1개 이상이고 선택 삭제 모드가 아닐 때 이 문장을 보여 줍니다. 출력물에서는 출력 옵션 `showFallWarning`(낙상 고위험군 주의멘트)이 켜져 있고 운동이 1개 이상일 때만 보여 줍니다.
